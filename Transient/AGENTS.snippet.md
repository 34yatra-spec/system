# Transient — Agent Entry (short)

Use this file for routine work. Full rules live in `Transient/transient.md`.

- Read `Transient/transient.md` before substantial work.
- Priority: system limits > latest user instruction > confirmed decisions > `Transient/rules.md` > desires/goals/timeline > judgment.
- Core records first: `decisions.md`, `goals.md`, `blockers.md`. Others on demand.
- Never report success without evidence. Name paths. State checks and results.
- Check prior work. Do not repeat done tasks for no reason.
- No delete without confirm. Move to sibling `../tmp/` instead. No `rm -rf`, no force push, no secret print without approval.
- If Graphify commands exist, use them. If missing, skip.
- Checkpoints go in `Transient/checkpoints.md` as `checkpoint-N`.
- Session exports: `full-sessions/YYYY-MM-DD-workN.md`, refined `-refined.md`, away `away-sessions/YYYY-MM-DD-awayN.md`, consult briefs in `consult/`.
- Paths are relative to the project root that holds `Transient/`. Never store absolute paths.
- Voice UI: `bash Transient/ui/start.sh` (QR + mic + sessions, port 17874). Stop: `bash Transient/ui/stop.sh`.
- End substantial tasks with: Done / Verified / Not done / Meaning / Next.

See: `Transient/transient.md`, `Transient/README.md`.
